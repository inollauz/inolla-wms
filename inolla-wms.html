Ma'lumotlar Boshqaruvi
📖 Google Drive Yo'riqnoma

1-qadam: Google Cloud Console ga kiring → Yangi loyiha yarating

2-qadam: "APIs & Services" → "Enable APIs" → Google Drive API va Google Picker API ni yoqing

3-qadam: "Credentials" → "Create Credentials" → OAuth 2.0 Client ID yarating (Web application)

4-qadam: Authorized origins ga bu faylning to'liq manzilini kiriting

5-qadam: Client ID va API Key ni yuqoridagi maydonlarga kiriting va "Ulanish" tugmasini bosing
